## 썸네일 훅 설계 규칙 (가장 중요 — 클릭을 결정한다)

`thumbnail_hook`은 영상 첫 프레임에 박혀 **정지 이미지(썸네일)로 노출되는 문장**이다.
채널 페이지·검색·추천에서 이 한 줄이 클릭 여부를 결정한다. 대본 요약이 아니다.

### 반드시 갖출 3요소
1. **자기관련성**: 시청자가 "이거 내 얘기다" 또는 "내가 지금 그러고 있다"고 느껴야 한다.
2. **미해결 긴장**: 읽고 나서 답이 궁금해야 한다. 답을 훅에 쓰면 클릭할 이유가 사라진다.
3. **구체성**: 막연한 일반론 금지. 특정 행동·상황·숫자로 좁힌다.

### 5공식 중 1개 선택 (이전 영상과 같은 공식 연속 사용 금지)
- **A 자기지목 진단형**: 특정 집단을 지목해 불안을 건드린다 → "잘 맞는 사람이 더 위험"
- **B 역설 주장형**: 상식을 정면으로 뒤집는다 → "그 사람은 도망치는 중"
- **C 실수 경고형**: 지금 하고 있는 행동이 손해라고 알린다 → "답장 빠른 게 관심은 아니다"
- **D 구체 수치 충격형**: 예상을 벗어나는 숫자를 던진다 → "당신은 2년 뒤 식는다"
- **E 미완결 단서형**: 결정적 순간만 제시하고 끊는다(문법은 유지) → "돈 얘기에서 갈린다"

### 절대 금지 (현재 채널 훅 201개 분석 결과 기반)
- ⛔ **`~이유` / `~법` / `~방법`으로 끝내기.** 현재 훅의 33%가 이 두 어미다. 강의 목차처럼 읽혀 클릭되지 않는다.
- ⛔ **결론·정답을 훅에 다 쓰기.** 예: "가스라이팅 단칼 격파법" → 답을 알려줬으니 볼 필요가 없다.
- ⛔ **공허한 강조어**: 진짜, 비밀, 충격, 소름, 대박, 놀라운, 미친. 정보량이 0이다.
- ⛔ **주제를 그대로 요약하기.** `{forced_topic}`을 줄인 문장은 훅이 아니다.
- ⛔ 나쁜 예: "호감 신호 알아보는 법" / "밀당이 통하는 이유" / "연애 성공의 비밀" — 전부 위 금지에 해당한다.

### 형식
- 공백 제외 **8~16자** (짧으면 밋밋하고 길면 썸네일에서 안 읽힌다)
- 마침표·느낌표·물결·이모지 금지
- 2줄로 나눌 때는 첫 줄에 충격을 배치하고 줄바꿈(\n)을 넣는다
- 위 좋은 예시를 그대로 베끼지 말고, 이번 주제에 맞춰 새로 만든다

## 출력 전 자체 검수 (반드시 1회에 통과해야 한다)

재작성 기회는 없다고 생각하고 한 번에 정확히 작성하라.

1. **길이**: `full_script`는 {min_chars}~{max_chars}자.
   글자수를 정확히 세기 어려우면 **문장 수로 맞춰라: 총 6~8문장, 한 문장 35~45자.**
   배분: 훅 1문장 + 공감 1~2문장 + 원리·해결 3~4문장 + CTA 1문장.
   `full_script`는 `hook` + `body` + `cta`를 순서대로 이어붙인 문장이며,
   세 필드를 합친 것과 **정확히 일치**해야 한다. 따로 쓰지 말고 이어붙여라.
   420자를 넘으면 즉시 거부된다.
2. **완결형 마무리**: `full_script`의 마지막 문장은 마침표로 끝나는 온전한 문장이어야 한다.
   아래 표현으로 끝나면 즉시 거부된다.
   왜냐하면 / 그래서 / 그런데 / 하지만 / 그렇다면 / 따라서 / 결국 / 즉 / 그리고 / 그러나 /
   때문에 / 덕분에 / 이라서 / 니까 / 라서 / 하며 / 하면서 / 면서 / 니까요 / 는데요 / 이니까 / 으니까
3. **제목 중복**: 위 '이전에 다룬 주제들' 목록의 어떤 제목과도 2글자 이상 핵심 단어가
   **3개 이상 겹치면 거부**된다. 숫자를 쓸 경우, 같은 숫자를 쓴 기존 제목과 핵심 단어가
   **1개만 겹쳐도 거부**된다. 목록을 읽고 어휘가 겹치지 않게 새로 지어라.
4. **썸네일 훅**: 공백 제외 8~16자. `~이유` / `~법` / `~방법` 종결 금지. 마침표·이모지 금지.

6. **JSON 형식**: 코드블록 표시나 설명 문장 없이 순수 JSON만 출력한다.
