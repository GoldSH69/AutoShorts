# AutoShorts - YouTube Shorts Automation Project

YouTube Shorts 자동 생성 및 배포 파이프라인 프로젝트입니다.

---

## ⚠️ AI 개발 및 소스 코드 수정 규칙 (Strict Rule)

**이 프로젝트에서 작업하는 모든 AI 어시스턴트는 대화 및 개발 시작 전 아래 수칙을 반드시 숙지해야 합니다.**

1. **사용자 승인 필수 (Explicit User Approval Required)**:
   - 사용자가 명시적으로 승인(Approval)하기 전에는 어떠한 소스 코드(`.py`), 프롬프트 템플릿(`.txt`), 혹은 설정 파일(`.yml`, `.json`)도 수정해서는 안 됩니다.
   - 단독 판단으로 개발을 진행하거나 임의로 코드를 수정하여 실행하는 행위는 엄격히 금지됩니다.

2. **작업 프로세스**:
   - **Step 1 (Research)**: 코드와 구조를 충분히 분석하고 이해합니다. (수정 금지)
   - **Step 2 (Implementation Plan)**: 구현 계획서(`implementation_plan.md`)를 작성하여 사용자에게 공유하고 피드백을 받습니다.
   - **Step 3 (Explicit Approval)**: 사용자가 계획을 검토한 후 명시적으로 **승인(Proceed 또는 승인 메시지)**한 경우에만 실제 소스 코드 수정 및 실행에 들어갑니다.
   - **Step 4 (Execution & Verification)**: 승인된 범위 내에서만 개발을 진행하고 결과를 검증합니다.
